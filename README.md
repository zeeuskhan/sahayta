# Sahayta / Utsav information page

A mobile-first festive information landing page built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Deploy
Import this repository into Vercel. No build command is required; the site is static.

## Safety
This is an independent informational page, not a government website. The ₹8,000 amount is a visual demo only and is not a claim of an actual benefit or payment. Verify schemes and eligibility only through linked official government portals.
